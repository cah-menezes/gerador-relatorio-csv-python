# 📊 Gerador de Relatório em CSV

Script em Python que lê dados de auditoria de um arquivo `.txt` e gera um relatório `.csv` formatado para abrir no Excel ou LibreOffice.

## ⚙️ Funcionalidades

- Lê e organiza dados de auditoria separados por ponto e vírgula
- Gera um arquivo `.csv` pronto para análise
- Usa list comprehension para transformar os dados

## 🚀 Como executar

```bash
git clone https://github.com/cah-menezes/gerador-relatorio-csv-python.git
cd gerador-relatorio-csv-python
python3 gerador_relatorio.py
```
